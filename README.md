# Antiprism triangulations have real-rooted h-polynomials

Code accompanying the paper of the same title by Deep Bhattacharjee. The paper proves
Conjectures 1.1 and 5.3 of Athanasiadis, Brunink and Juhnke-Kubitzke,
*Combinatorics of antiprism triangulations*, Discrete Comput. Geom. 68 (2022) 72–106.

* `lean/`: Lean 4 + Mathlib certificate of the general identity, the sign lemma and the
  finite data (kernel-checked, standard axioms only).
* `julia/`: exact Julia verification of all identities and interlacing relations for n <= 18.
